📝 How to Configure SMTP Secrets in Supabase

If the test shows secrets are missing, follow these steps:

  1. Go to Supabase Dashboard
  2. Select your project: lsxqumkfmqkvtuwpbhxy
  3. Click Project Settings (gear icon in sidebar)
  4. Click Edge Functions in the left menu
  5. Scroll down to Secrets section
  6. Add these 5 secrets (click "Add Secret" for each):
    • SMTP_HOST = mail.souvenirpickers.com
    • SMTP_PORT = 587
    • SMTP_USER = support@souvenirpickers.com
    • SMTP_PASS = [your Bluehost email password]
    • SMTP_FROM = support@souvenirpickers.com
  7. Click Save after adding each secret
  8. Wait 1 minute for secrets to propagate, then test again
