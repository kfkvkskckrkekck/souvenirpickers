This will test if the SMTP configuration is working correctly

⚠️ Important: If the password reset link in the email doesn't work, you need to configure redirect URLs:
  1. Go to Supabase Auth Settings
  2. Add these URLs to "Redirect URLs":
    • https://souvenirpickers.com/**
    • http://localhost:5173/**
  3. Set "Site URL" to: https://souvenirpickers.com
